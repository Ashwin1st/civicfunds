What CivicFunds has, and what it doesn't

A tool that only shows you what it found is easy to mistake for a tool that found everything. This page is here so that mistake is harder to make.

County scope, not district scope

CivicFunds indexes three whole counties — Duval, Clay and Nassau. That is deliberately not the same shape as a congressional district, and the difference matters enough to state plainly.

Florida's 4th District covers all of Clay, all of Nassau, and the part of Duval west of the St. Johns River. The rest of Duval — southeast Jacksonville — is Florida's 5th District, together with all of St. Johns County, which this index does not cover at all.

So this index is a superset of FL-04 within these counties and a subset of FL-05. Every source here filters on county, because county is what the federal and state systems accept. Congressional district would have to be computed per project by point-in-polygon, and that is not built yet — so where a district has not been tested, the app says so rather than naming one.

Fetched by a program, or typed in by a person

Most records here arrived through an adapter that called a government API. A few were read off a published PDF and typed in by hand, because no adapter exists for those sources yet. Those records carry MANUAL in their source system, visible on screen, so the distinction is never hidden. The figures and citations are equally real; the path they took is not the same, and pretending otherwise would be the first small lie.

Why there is never a total

Public spending figures measure different things. An appropriation is budget authority a legislature enacted. An obligation is money an agency has legally committed. An outlay is cash that has actually left the treasury. A programmed amount is a line in a multi-year plan that gets revised every year. A loan's face value is none of those.

Adding them produces a number that is not true in any sense. CivicFunds will not do it, and the rule is enforced in the code rather than left to discipline: the Amount type carries its measurement class, and adding two amounts of different classes throws an exception. You cannot write code in this project that sums an obligation and an outlay.

There is a second reason, which is subtler. Even two figures of the same class can be the same dollars seen twice — federal money passed through a state work programme appears in both governments' books. Until the relationship between two records has been established, adding them risks double-counting. So the app shows the ledger and says what it does not know.

What was rejected on the way in

USAspending publishes county-level rollups with the recipient replaced by MULTIPLE RECIPIENTS, and privacy-suppressed rows reading REDACTED DUE TO PII. Both always carry a county code, so a naive county filter selects exactly those. They are not projects, and mapping them would put things on screen that look real and are not. They are detected, dropped and counted during ingestion.

Records are not dollars

Counting records is not a proxy for counting money. One federal formula programme can arrive as a single record covering many projects, while a state work programme files one row per phase per year. Wherever this site shows a count, it is a count of rows in an index, and it says so.

Every figure here comes from a government record, and every record keeps the URL it came from and the date it was fetched. Where a source published nothing, CivicFunds says so rather than filling the gap.
