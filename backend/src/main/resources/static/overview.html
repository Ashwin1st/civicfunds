What is indexed

Every figure on this page is a count of records. None of them is a sum of money, and there is no endpoint behind this page that could produce one — the records measure different things, so a combined dollar figure would describe nothing that exists.

Every figure here comes from a government record, and every record keeps the URL it came from and the date it was fetched. Where a source published nothing, CivicFunds says so rather than filling the gap.

Counts of records are not a proxy for dollars. One federal formula programme can arrive as a single record covering many projects, while a state work programme files one row per phase per year. A tall bar means more rows, not more money.
